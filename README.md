# CalculaJuros

Calculadora moderna de juros simples e compostos com simulação de empréstimos.

🔗 Acesse o projeto: https://seu-link-aqui.com

---

## 📋 Sobre o projeto

O **CalculaJuros** é uma aplicação desenvolvida para facilitar cálculos financeiros relacionados a juros simples, juros compostos e simulações de empréstimos.

A ferramenta foi pensada para apresentar os resultados de maneira clara e visual, permitindo que o usuário informe os valores e consiga compreender o impacto dos juros ao longo do tempo.

Além dos cálculos, o projeto possui uma interface responsiva e foi desenvolvido como PWA, permitindo sua instalação em dispositivos móveis e computadores.

---

## ✨ Funcionalidades

* Cálculo de juros simples e compostos
* Simulação de empréstimos com parcelas
* Interface moderna e responsiva
* Animações suaves
* Funciona offline (PWA)
* Instalável no celular e desktop
* Histórico de cálculos
* Alternância de tema
* Interface adaptada para diferentes tamanhos de tela
* Organização dos cálculos em componentes reutilizáveis

---

## 🛠️ Tecnologias

* React 19
* TypeScript
* Tailwind CSS v4
* Framer Motion
* Lucide React
* Vite 6
* Progressive Web App (PWA)

---

## 🧮 Objetivo do projeto

O objetivo é disponibilizar uma ferramenta prática para realizar simulações financeiras sem a necessidade de utilizar planilhas ou cálculos manuais.

O projeto também foi desenvolvido como uma demonstração de aplicação Front-end moderna, utilizando componentes, tipagem estática, organização de lógica de cálculo e uma interface responsiva.

---

## 📱 Experiência PWA

Por utilizar Progressive Web App, a aplicação pode funcionar como uma experiência semelhante a um aplicativo instalado.

Isso permite utilizar a ferramenta em diferentes dispositivos, mantendo uma interface adaptada para telas menores e maiores.

## 🚀 Como executar localmente

### 1. Clone o repositório

```bash
git clone https://github.com/programadorcosta87-eng/CalculaJuros.git
```

### 2. Entre na pasta

```bash
cd CalculaJuros
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Inicie o projeto

```bash
npm run dev
```

O projeto utiliza a porta `3000` em desenvolvimento.

Acesse:

```text
http://localhost:3000
```

## 📦 Build para produção

```bash
npm run build
```
