# CalculaJuros
**Acesse o site:** https://meu-site.com

CalculaJuros é uma aplicação web e PWA (Progressive Web App) para simulações financeiras de juros simples e compostos.  
​**Tecnologias Utilizadas**
- ​React 19
- ​TypeScript
- ​Tailwind CSS v4
- ​Motion (Framer Motion)
- ​Lucide React
- ​Vite 6
- ​Express
- ​Service Workers & Web Manifest (PWA)
