# CalculaJuros

Calculadora de juros profissional (simples e compostos) com suporte a PWA.

## Rodar localmente

**Pré-requisitos:** Node.js

1. Instale as dependências:
   ```bash
   npm install
   ```
2. Rode o app:
   ```bash
   npm run dev
   ```
3. Para build de produção:
   ```bash
   npm run build
   ```
