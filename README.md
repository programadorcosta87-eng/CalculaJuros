# CalculaJuros

Calculadora moderna de juros simples e compostos com simulação de empréstimos.

🔗 **Acesse o projeto:** [https://seu-link-aqui.com](https://seu-link-aqui.com)

---

## ✨ Funcionalidades

- Cálculo de juros simples e compostos
- Simulação de empréstimos com parcelas
- Interface moderna e responsiva
- Animações suaves
- Funciona offline (PWA)
- Instalável no celular e desktop

## 🛠️ Tecnologias

- React 19
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide React
- Vite 6
- Progressive Web App (PWA)
